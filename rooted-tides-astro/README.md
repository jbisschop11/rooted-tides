# Rooted Tides (Astro)

A lightweight, high-performance website for Rooted Tides Reiki.

## Quick start

1. Install dependencies
   ```bash
   npm install
   ```

2. Run locally
   ```bash
   npm run dev
   ```

3. Build for production
   ```bash
   npm run build
   npm run preview
   ```

## Deploy (simple options)

### Netlify (easy)
- New site from Git
- Build command: `npm run build`
- Publish directory: `dist`

### Vercel
- Framework preset: Astro
- Build command: `npm run build`
- Output: `dist`

### GitHub Pages
Astro can deploy to GitHub Pages, but you’ll likely want a custom domain. If you want Pages, tell me your repo name and whether it’s a user site or project site and I’ll give the exact config.
